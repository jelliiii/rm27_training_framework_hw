# 学习记录

## 操作流程：

拉低 CS → 发送 地址 & 0x7F（bit0=0）→ 发送数据 → 拉高 CS。
读操作流程（加速度计特殊）：

拉低 CS → 发送 地址 | 0x80（bit0=1）→ 再发送一个 dummy 字节（任意值） → 接收数据 → 拉高 CS。
加速度计读取时，第一个返回的字节是无效的，必须读取两次才能获得真实值。陀螺仪则使用标准 SPI 读协议，不需要 dummy 字节。

## 数据读取
陀螺仪：
发送：地址 | 0x80 → 空字节 → 空字节……
接收：    忽略   → 数据0  → 数据1……

加速度计：
发送：地址 | 0x80 → 空字节 → 空字节 → 空字节……
接收：    忽略   → dummy  → 数据0  → 数据1……

传感器	数据寄存器起始地址	数据长度
加速度计	0x12（X 轴低字节）	6 字节（X/Y/Z 各 2 字节）
陀螺仪	0x02（Rate X 低字节）	6 字节
